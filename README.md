# Ateneo — Descargas Oficiales (Android)

Lector offline para Android compatible con libros, documentos, manga, cómics y anotaciones sin rastreo ni cuentas.

## Descarga rápida

Descarga siempre la última versión desde la sección **[Releases](https://github.com/Daniel1bolivar/ateneo-releases/releases/latest)**.

### Cómo actualizar sin perder libros ni notas
* Desde **Ateneo v1.1** en adelante, todas las versiones usan la misma firma digital.
* Puedes abrir **Ajustes -> Buscar actualización (OTA)** dentro de la app o descargar el nuevo .apk desde Releases e instalarlo directamente encima (sin desinstalar).

## Formatos compatibles (100% offline)
* **Libros y documentos:** .epub (con imágenes embebidas), .pdf (texto refluible para móvil), .md, .txt, .docx y .fb2.
* **Manga, cómics y webtoons:** .cbz / .zip con vista **Webtoon** (scroll vertical), **Manga RTL** (derecha a izquierda) y **Cómic LTR** con zoom.

## Guía rápida para beta testers
1. **Abrir libros viejos del teléfono:** puedes usar el botón **Cargar** dentro de Ateneo o tocar cualquier libro desde tu Administrador de archivos / WhatsApp / Drive y elegir **Abrir con -> Ateneo** (o **Compartir -> Ateneo**).
2. **Miniaturas y portadas:** Ateneo extrae automáticamente la portada en .epub, .pdf, .docx, .fb2 y .cbz. Toca el menú **⋮** de cualquier tarjeta para **subir una imagen propia** desde tu galería o **elegir una imagen interna del propio libro**.
3. **Notas estilo burbuja:** selecciona cualquier frase o haz **doble toque** en un párrafo para resaltar y escribir una nota sin perder espacio de lectura.
4. **Organización y lectura:** estanterías (Leyendo, Pendiente, Terminado), series, etiquetas, calificación por estrellas, marcadores, lectura enfocada, voz alta (TTS), fuentes .ttf personalizadas, botones de volumen, brillo rápido y estadísticas locales.
5. **Respaldos y exportación:** desde el lector puedes compartir notas en Markdown, **Obsidian**, **CSV** o exportar un respaldo .json completo.
